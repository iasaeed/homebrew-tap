# iasaeed/homebrew-tap

Homebrew tap for iasaeed tools.

```sh
brew install iasaeed/tap/xcpurge
```

Requires Homebrew (https://brew.sh) and Xcode 26 or newer.

| Formula | Description |
| --- | --- |
| [xcpurge](https://github.com/iasaeed/xcpurge) | Find unused assets, localized strings and files in Xcode/SwiftPM projects |
